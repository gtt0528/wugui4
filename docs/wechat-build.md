# 微信小游戏：注册 → 构建 → 真机 → 体验版

> 这份文档对应「乌龟4」当前工程（Cocos Creator 2.4.15，纯代码 UI，无美术资源）。
> 命令行 `CocosCreator.exe --build ...` 在 2.4.15 上会报 `bad option`，所以走编辑器图形界面。

---

## 0. 先认清一件事：类目

个人主体**不能选择「牌类」**，而「乌龟4」的玩法核心是手牌 + 轮流出牌比大小 + 对抗输赢，属于牌类。
所以这份文档带你做到的是 **体验版（给指定的人玩）**，不是公开上架。

- ✅ 体验版：不需要版号、不需要过审，扫码即玩，够你做线下实测和演示视频；
- ❌ 公开上架：需要企业主体 + 版号（牌类），6–12 个月、数万元起；
- ⚠️ 硬报「休闲益智」蒙混：可能过审后被复查下架，且会在主体上留违规记录，影响你以后所有小程序/小游戏注册。

---

## 1. 注册小游戏账号，拿 AppID（只有你能做）

1. 打开 https://mp.weixin.qq.com → 立即注册 → 选「**小程序**」；
2. 邮箱激活 → 主体类型选「**个人**」→ 身份证 + 本人微信扫码验证；
3. 登录后台 → 「设置 → 基本设置」里能看到 **AppID（wx 开头 18 位）**；
4. 同一个邮箱不能重复注册，个人主体有名额上限（目前 5 个），别乱试。

> AppID 是「这个游戏在微信里的身份证」，构建和开发者工具都要用。
> 没有它也能先在开发者工具里用「测试号」跑本地预览，但**不能上传体验版**。

## 2. 构建前，工程这边要确认的三件事

| 项目 | 现在状态 | 说明 |
|---|---|---|
| 起始场景 | ✅ `menu`（uuid `ce346cb3…`） | `settings/project.json` 已设 |
| 设计分辨率 | ✅ 1280×720 横屏 | 两个场景在代码里 `setDesignResolutionSize(1280,720,SHOW_ALL)`，构建时设备方向选**横屏**即可 |
| 服务端地址 | ⚠️ 占位符 | `assets/scripts/net/Config.ts` 的 `PROD_WS = 'wss://YOUR-DOMAIN.com/ws'`，**没换真域名之前，真机连不上对战服**（界面会明确提示） |

### 只想先看能不能跑起来（不联机）
可以先不配域名，构建后在开发者工具里点「预览」看主菜单和单机 AI 对战是否正常。
联机必须等第 5 步的域名。

## 3. 在 Cocos Creator 里构建

1. 打开编辑器 → 顶部菜单「**项目 → 构建发布**」（Ctrl+Shift+B）；
2. 左侧平台选「**微信小游戏**」；
3. 参数按下面填：

| 参数 | 填什么 | 为什么 |
|---|---|---|
| 发布路径 | `build`（默认） | 已在 .gitignore，不会进仓库 |
| 初始场景 | `menu` | 主菜单 |
| AppID | 你的 `wx…`；没有就留空 | 留空构建也能出包，导入开发者工具时再填 |
| 设备方向 | **横屏 landscape** | 玩法是 1280×720 横版，竖屏会挤成一团 |
| 调试模式 | 关（debug=false） | 出包更小；排查问题时再打开 |
| Source Maps | 关 | 同上 |
| MD5 Cache | 开或关都行 | 上线建议开，避免缓存旧 JS |
| 分包 | 不用 | 当前代码 + 引擎远小于主包 4MB 上限 |

4. 点「**构建**」，等进度条走完（首次 1–3 分钟）。
5. 产物在 `build/wechatgame/`，里面应该有：
   - `game.js`、`game.json`、`project.config.json`
   - `cocos2d-js-min.js`（引擎）
   - `assets/`（脚本编译产物，你的 9 千多行 TS 会压成一两个 bundle）

**体积自检**：右键 `build/wechatgame` 看总大小。纯代码项目一般在 1.5–2.5MB（主要是引擎），
主包 4MB 上限很宽裕。如果超了，先看是不是把 `library/`、`temp/` 之类误拷进去了。

---

## 4. 微信开发者工具：真机跑起来

1. 下载「微信开发者工具 · 稳定版」：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开 → 「导入项目」→ 目录选 `D:\cocosProject\wugui4\build\wechatgame` → 填 AppID（或选测试号）；
3. 模拟器里应出现主菜单。**注意：小游戏没有 DOM，模拟器只作参考，一定要真机预览**；
4. 点右上角「**预览**」→ 生成二维码 → 手机微信扫码 → 真机上跑。

### 真机必查清单

- [ ] 主菜单能进、能点；
- [ ] 4 台手机（或 1 台手机 + 3 个网页）能进同一房间并打完一局；
- [ ] 有人锁屏 30 秒 → 另外三人不崩，他能坐回原位；
- [ ] 交牌阶段每步有 20 秒倒计时，超时会自动交；
- [ ] 横屏正常，刘海屏不挡按钮。

## 5. 联机要用的域名（体验版也绕不过）

微信里 `wx.connectSocket` 只能连 **wss://**，且域名必须：

1. 已 **ICP 备案**（个人可备案，云厂商代办，约 1–3 周）；
2. 配好 **SSL 证书**（阿里云/腾讯云免费证书即可）；
3. 在「微信公众平台 → 开发 → 开发管理 → 开发设置 → **服务器域名** → socket 合法域名」里加上 `wss://你的域名`；
4. 反向代理：Nginx 把 `wss://你的域名/ws` 转发到本机 `ws://127.0.0.1:8090`（对战服不需要对公网直接暴露 8090）；
5. 改 `assets/scripts/net/Config.ts`：

```ts
export const PROD_WS = 'wss://你的域名/ws';
export const PROD_HTTP = 'https://你的域名';   // backend 8081 的反代
```

改完**重新构建**才会生效。

### Nginx 参考（放在服务器上）

```nginx
location /ws {
    proxy_pass http://127.0.0.1:8090;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_read_timeout 300s;   # 别让长连接被 60 秒切断
}
```

> 提醒：对战服目前是单进程内存房间。体验版够用；
> 真要多人长期在线，需要多进程 + Redis 房间路由，这是另一个量级的工作。

## 6. 上传体验版

1. 开发者工具点「**上传**」→ 填版本号（如 `0.1.0`）+ 备注；
2. 公众平台 →「管理 → 版本管理」→ 找到刚上传的开发版本 → 「**选为体验版**」；
3. 「成员管理 → 体验成员」里加上朋友的微信号（数量有上限，以后台为准）；
4. 体验成员打开小程序搜索页/分享卡片即可进入；
5. 每改一次代码都要重新构建 + 上传 + 选为体验版。

## 7. 常见翻车点

| 现象 | 原因 |
|---|---|
| 真机白屏 / 黑屏 | 常见于 JS 报错，打开开发者工具「调试 → 真机调试」看 console |
| 一直「正在连接对战服」 | `PROD_WS` 还是占位域名；或后台没加 socket 合法域名；或证书/Nginx 没配好 |
| 提示「不在以下 socket 合法域名列表中」 | 第 5 步第 3 条没做，或改了域名没重新构建 |
| 竖屏 / 界面错位 | 构建时设备方向没选横屏 |
| 上传失败「包体超过限制」 | 主包超 4MB，检查是否混入了不该有的资源 |
| 手机切后台回来掉线 | 已做心跳 + 自动重连；若仍失败，看服务端日志是否 `[心跳]` 回收过 |
| 键盘输不了房间号 | 房间号是本项目自绘的数字键盘，不依赖系统输入法；若点不动，检查点击区域被遮挡 |
